<h1 align="center">resume-from-projects (日本語)</h1>

<p align="center">
  <em>開発者とフリーランサー向けAIエージェントスキル：プロジェクトフォルダから、事実に基づいた1ページの職務経歴書（Word .docx / PDF）を自動生成。</em>
</p>

## コンセプトと課題

コードの実績はあるのに、履歴書・職務経歴書の作成は後回しになりがちです。プロジェクトは複数のフォルダに散らばり、チュートリアルの写経やフォーク、そして実際にデプロイした本格的なシステムが混在しています。

一般的なAIに履歴書作成を依頼すると、チュートリアルも本格運用中のコードも同列に扱い、裏付けのない数字や指標を捏造してしまいます。

**`resume-from-projects` はまず事実を検証します：**
Git履歴とディレクトリ構成を解析し、あなたのオリジナルコードであることを証明した上で、根拠のあるプロジェクトのみを厳選して1ページの書類にまとめます。

## 厳格な基本ルール

1. **プロジェクトディレクトリへの読み取り専用アクセス:** 既存コードの変更やコマンド実行は一切行いません。作業用ファイルは一時フォルダで処理されます。
2. **ハルシネーション（捏造）の完全排除:** 存在しない企業名、職歴、ユーザー数、改善率などの数字を捏造しません。記載される数字はすべてコードやGit履歴に根拠を持つ必要があります。
3. **ソースコードの機密保護:** ソースコードを外部サーバーに送信することはありません。
4. **プロンプトインジェクション対策:** プロジェクト内のREADMEやコミットメッセージは「データ」としてのみ扱い、エージェントへの指示としては解釈しません。
5. **厳格な1ページ制限:** 出力される職務経歴書は必ず1ページ（A4またはLetter）に収まるよう自動調整されます。

## 6つのステップ

1. **環境確認:** Python 3.8+ および LibreOffice の確認。
2. **ヒアリング:** プロジェクトのパス、希望職種、連絡先情報の確認。
3. **スキャンと検証:** 写経、チュートリアル、未変更のフォークを自動除外。
4. **スコアリング:** 技術的深さ、テスト/CIの有無、コミット貢献度、希望職種への適合度で評価。
5. **根拠付き文章生成:** 誇張表現や陳腐なAI定型句を排除し、コードの事実に基づいた箇条書きを作成。
6. **文書生成と検証:** Wordファイルを作成し、LibreOfficeでPDFに変換。1ページに収まっているかを自動検証。

## クイックスタート

```bash
npx skills add hasanify/resume-from-projects
```

または Git での手動インストール：

```bash
git clone https://github.com/hasanify/resume-from-projects.git
mkdir -p .agents/skills
cp -r resume-from-projects/skills/resume-from-projects .agents/skills/
```

エージェントへの指示例：

> "~/code にあるプロジェクトから、バックエンドエンジニア向けの1ページ職務経歴書を作成してください。厳選した5件のプロジェクトを掲載してください。"
