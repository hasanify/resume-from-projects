# Resume from Projects (Cline Rule)

When asked to generate a resume or portfolio CV from code repositories:

1. Follow `skills/resume-from-projects/SKILL.md`.
2. Do not edit, build, or execute files within the scanned project directories.
3. Verify origin and git commit share to exclude tutorial exercises or third-party forks.
4. Ground every bullet point in verifiable code artifacts or git commits. Reject corporate buzzwords and unverified metrics.
5. Produce a verified, single-page `.docx` and `.pdf` resume using the bundled Python scripts.
